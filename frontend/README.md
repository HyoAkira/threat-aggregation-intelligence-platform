# Threat Intelligence Frontend

A standalone static single-page application built with React, Vite, and
[TanStack Router](https://tanstack.com/router) file-based routing. There is no
frontend SSR server: the production artifact is static HTML, JavaScript, CSS,
and assets.

## Getting started

```bash
npm ci
npm run dev
```

Development serves the application from `http://localhost:3000`. The Vite dev
server proxies same-origin `/api/*` requests to the local backend at
`http://localhost:5092` (see `vite.config.ts`).

## Scripts

- `npm run dev` – Vite development server with HMR and the `/api` proxy.
- `npm run generate-routes` – regenerate `src/routeTree.gen.ts` from
  `src/routes`.
- `npm run build` – produce the static production build in `dist/`
  (`index.html` plus hashed assets; no server bundle).
- `npm run preview` – serve the built `dist/` output locally for a production
  smoke test.
- `npm test` – Jest unit and component tests.
- `npm run test:e2e` – Playwright browser tests against the built static
  preview.
- `npm run lint`, `npm run format`, `npm run check` – ESLint and Prettier.

## Routing and startup

File-based routes live in `src/routes`; `src/routeTree.gen.ts` is generated by
the TanStack Router Vite plugin (and by `npm run generate-routes`). `src/main.tsx`
is the browser entry: it imports the global stylesheet, creates the configured
router, and mounts `<RouterProvider>` into the `#root` element declared in
`index.html`. Client-side route guards, session restoration from browser session
storage, deep-link resume, route search state, and route-level code splitting are
all preserved.

## Static hosting contract

The API is only ever called on the same origin through relative `/api/*` URLs;
the browser never sees a cross-origin API base. A static host must:

- serve `dist/` as the document root;
- proxy `/api/*` to the backend on the same origin;
- apply history fallback so non-file client routes (for example `/browse` and
  `/admin/providers`) return `index.html`; and
- return 404 (not `index.html`) for missing file-like asset requests.

The production configuration is in `nginx.conf`, packaged by the multi-stage
`Dockerfile`. From the repository root, `docker compose up -d --build --wait`
serves it at http://localhost:3000. Complete environment and secret preparation
in [the root README](../README.md) first. Stop the Compose frontend before
running Vite on the same port.

## Styling

Tailwind CSS v4 is wired through `@tailwindcss/vite` and imported from
`src/styles.css`.
